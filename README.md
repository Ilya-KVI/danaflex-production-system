# Danaflex Production System 🏭

## Описание проекта

**Danaflex Production System** — это веб-приложение для мониторинга и управления производственными заказами.

Проект реализован с использованием современного стека:

* **Backend:** Laravel (PHP)
* **Frontend:** Vue 3
* **Связь Backend + Frontend:** Inertia.js
* **Стилизация:** Tailwind CSS
* **База данных:** MySQL / MariaDB

Приложение моделирует работу производственного предприятия: создание заказов, изменение статусов, контроль производственных линий и просмотр текущей информации о производстве.

---

# Основной функционал

## 📦 Управление производственными заказами

Реализованы возможности:

* создание нового производственного заказа;
* просмотр списка всех заказов;
* просмотр детальной информации о заказе;
* редактирование заказа;
* удаление заказа;
* изменение статуса заказа.

Доступные статусы:

* Новый
* В производстве
* Готово

---

## 🔎 Поиск и фильтрация заказов

В разделе заказов реализованы:

* поиск по имени клиента;
* поиск по материалу;
* фильтрация по статусам.

Это позволяет быстро находить необходимые производственные заявки.

---

## 🏭 Управление производственными линиями

Реализована работа с производственными линиями:

* запуск линии;
* остановка линии;
* изменение состояния оборудования;
* отображение температуры;
* отображение загрузки линии;
* отображение используемого материала.

При запуске линии автоматически обновляются показатели:

* температура оборудования;
* процент загрузки;
* статус линии.

---

## 📊 Dashboard мониторинга

Главная страница содержит:

* количество всех заказов;
* количество заказов в производстве;
* количество завершённых заказов;
* состояние производственных линий;
* последние производственные заказы.

Dashboard позволяет быстро оценить текущее состояние производства.

---

## 📝 Производственные логи

Добавлена система журналирования действий.

В логах сохраняются события:

* запуск производственной линии;
* остановка производственной линии.

---

# Frontend

Frontend реализован на **Vue 3** с использованием:

* Composition API;
* `script setup`;
* реактивных данных через `ref`;
* вычисляемых свойств через `computed`;
* компонентов Inertia.js для навигации без перезагрузки страницы.

Используется взаимодействие с Laravel через Inertia Router:

* GET-запросы для страниц;
* POST-запросы для действий;
* PUT-запросы для обновления данных;
* DELETE-запросы для удаления.

---

# Backend

Backend реализован на Laravel.

Используются:

* контроллеры;
* модели Eloquent;
* миграции базы данных;
* валидация входящих данных;
* маршрутизация Laravel;
* связи моделей.

Основные сущности:

* производственные заказы;
* производственные линии;
* производственные логи.

# Запуск проекта

## Установка зависимостей PHP

```bash
composer install
```

## Установка зависимостей Frontend

```bash
npm install
```

## Настройка окружения

Создать файл `.env` и настроить подключение к базе данных.

Пример:

```env
DB_DATABASE=danaflex_production
DB_USERNAME=root
DB_PASSWORD=
```

---

## Выполнение миграций

```bash
php artisan migrate
```

---

## Запуск Laravel

```bash
php artisan serve
```

---

## Запуск Vue/Vite

```bash
npm run dev
```

После запуска приложение доступно через браузер.
